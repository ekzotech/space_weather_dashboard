# Выпуск и откат

Собирайте образ из чистой рабочей копии проверенного коммита. Помечайте образы хешами коммитов и сохраняйте предыдущий рабочий образ до завершения проверки выпуска.

```sh
docker build --tag space-weather:<commit> .
docker run -d --name space-weather-candidate -p 127.0.0.1:39000:3000 space-weather:<commit>
docker inspect --format '{{.State.Health.Status}}' space-weather-candidate
curl --fail http://127.0.0.1:39000/api/health
curl --fail http://127.0.0.1:39000/
```

Замените `<commit>` хешем коммита. Дождитесь состояния `healthy`, откройте дашборд и проверьте графики и прогноз для города. После проверки переключите обратный прокси на новый контейнер. Метрики доступны через `/api/metrics`. Используйте доступ к этому маршруту только из сети мониторинга, если экземпляр открыт в интернете.

Для отката переключите прокси на предыдущий рабочий контейнер. Если контейнер уже остановлен, запустите сохранённый образ с предыдущим тегом на свободном локальном порту и дождитесь `healthy` перед переключением. Проверьте `/api/health` и страницу снаружи прокси. Образы не требуют миграций или постоянных томов.
